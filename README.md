# Automatic Patent Analysis Report Generation System


## Introduction

After the user inputs a technical topic, the large model begins to prepare a technology map and retrieve patents. It then starts composing patent analysis content. The generated patent analysis report can be downloaded in Word format.

[![demo video](https://img.youtube.com/vi/6y9-f7DCpZI/0.jpg)](https://www.youtube.com/watch?v=6y9-f7DCpZI)

## Requirements

- Python 3.10.x
- Required Python packages listed in `requirements.txt`

## Install

1. Installation:
   ```sh
   git clone -b patent_anaysis_agent git@github.com:awesome-patent-mining/patent_anaysis_agent_for_hackathon.git
   ```

2. Install the required Python packages:
   ```sh
   pip install -r requirements.txt
   ```
